# 🌸 Lilac Dreamer – Interactive Portfolio Resume

## Project info

Welcome to Lilac Dreamer, a modern, elegant, and interactive resume web app designed with passion and built for impact. This project showcases my skills, experience, and creative touch in a sleek digital format, optimized for both desktop and mobile experiences.

This web application is a dynamic, single-page resume designed to reflect both professional and personal aesthetics—featuring smooth animations, responsive design, and intuitive navigation. It serves as a personal branding tool that blends functionality with visual storytelling.

## 🛠️ Tech Stack

This project is built using a modern frontend tech stack:

Vite – lightning-fast build tool for front-end development

React – UI library for building interactive components

TypeScript – type-safe JavaScript for better developer experience

Tailwind CSS – utility-first CSS for custom styling

shadcn/ui – accessible, unstyled components for flexibility

**Deployment**

You can deploy this project using platforms like Netlify, Vercel, or GitHub Pages for fast and reliable hosting.
If you prefer to work locally using your own IDE, simply clone the repo and push your changes as needed.
The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

Follow these steps:

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```
